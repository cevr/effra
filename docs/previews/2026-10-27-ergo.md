# 2026-10-27: the language is Ergo

Labels: **Tested candidate**. Ticket: [#218](https://github.com/cevr/ergo/issues/218). This preview records a rename, not a change to how source reads: every earlier preview stays unchanged and keeps the name Effra, because a preview is a snapshot of its day.

The owner, 2026-10-27: "I just pick Ergo for now. This is a private project, so if it becomes big we can try to make a whole work or whatever, but for now let's just call it Ergo".

## What changed

| Before | Now |
| --- | --- |
| Effra | Ergo |
| `ef check main.ef` (binary `bin/ef`, package `cmd/ef`) | `ergo check main.ef` (binary `bin/ergo`, package `cmd/ergo`) |
| manifest `effra.json` | manifest `ergo.json` |
| `effra-2026/formatter-1` and the other edition and tool identities | `ergo-2026/formatter-1`, and the same change in every identity |
| Go module `effra.local/prototype` | Go module `ergo.local/prototype` |
| bundled modules `effra/json`, `effra/data`, … | `ergo/json`, `ergo/data`, … |
| runtime package `runtime/effra` | runtime package `runtime/ergo` |
| MCP server and LSP language id `effra` | `ergo` |
| `EFFRA_*` environment variables, `effra-lint-disable-next-line` | `ERGO_*`, `ergo-lint-disable-next-line` |
| `github.com/cevr/effra` | `github.com/cevr/ergo` (the old URLs redirect) |

## Tested candidate: the renamed CLI

Run at commit `2c76d055` of branch `wf10/sweep`, in a scratch directory that holds `main.ef` and the manifest `ergo.json` with `{"edition": "2026"}`: `ergo check main.ef` exits 0, `ergo fmt --check main.ef` reports "already formatted main.ef", and `ergo run main.ef` prints `hello from ergo`.

```go
package hello

func main() needs Console {
	Console.Println("hello from ergo")
}
```

## Kept

- **The `.ef` source extension.** [#205](https://github.com/cevr/ergo/issues/205) decides `.ergo` when it retires the legacy front end, so the legacy fixtures are not churned twice. The `//ef:go` directive, the registered `EF` diagnostic codes and the `EFMT_` formatter codes keep their spelling too: they are stable identifiers that tools and tests match on, and they rename, if at all, with the extension.
- **History.** Research notes under `docs/research/`, recorded receipts and runs, dated plans, earlier previews, past CHANGELOG entries, the frozen prototype `prototypes/sketch9` and quoted owner text keep the name they were written with.
- **The local checkout directory** keeps its name; renaming it is an owner action.
