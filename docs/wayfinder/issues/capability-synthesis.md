# Implement the accepted capability and lawful-runtime synthesis

Turn the accepted synthesis design into finite, independently gated repository units. The design is a source-backed decision artifact only; it does not implement externs, resource types, receiver methods, equality, host laws or runtime substitution.

## Acceptance

- Implement bundled-only extern scope/catalog facts, target-qualified host bindings and explicit ABI/failure/service rows. User extern escape, ambient capability admission and invalid target bindings diagnose.
- Implement constructor-less `extern [resource] type` and owner-controlled `pub readonly` data construction/ingress with nominal identity, ownership and equality/hash controls. Resource handles have no Effra constructors or structural codec shortcut.
- Implement ordinary receiver methods, pipe and constant-only defaults only where their checked prerequisites hold. Resolution is receiver-owned, source order and public rows remain visible, and no overload/extension/implicit witness search is introduced.
- Define and execute the finite lawful-runtime evidence suite in the [lawful runtime contract](../../research/lawful-runtime-contract.md): RS1 is the P1–P12/R1–R15 cross-target partial-order suite with its R1/R4/R7/R11 gaps and m1–m3 controls; RS2 separately makes P9 managed wait public, keeps latch/layers on the public core and checks for private-core references. Distinguish nominally checked, trusted decision, tested law, refuted and unresolved/unavailable evidence; preserve cancellation classification, defects, cleanup causes and completed shutdown.
- Implement provider selection only for a scoped, reviewed lawful effect/runtime contract. Pinned Effect remains the default/reference provider and the current JS ABI remains Effect-compatible; an alternate userland provider must declare its actual representation, ABI, effect/service/failure/ownership rows, cancellation and cleanup behavior, and machine interoperation rather than pretending a different representation is the default. Exercise two same-target unrelated provider callers where that contract is selected, plus negative controls for implicit execution, row mismatch and incomplete cleanup. A visible runtime selection remains deferred until a second real provider exists.
- Keep public contracts, inspection, source revisions and provider selection coherent across Go/JS. No hidden `any`, erased `R`, private runtime hook or benchmark-specific facade. Each unit needs causal negative controls, full gate and independent frozen review.

Synthesis remains implementation work after the accepted design review. It does not close any HITL ticket or establish a production release by prose.
