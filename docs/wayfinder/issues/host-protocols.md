# Native Go receiver methods and interface assignment

Unit2 of the [Go protocol contract](../../specs/go-protocol-interop.md): use Go's method/assignment authority, preserve native dynamic identity and optional I/O/filesystem methods, retain complete results. Public cases cover copy dispatch, data plus EOF, short writes, pointer/value method sets and incompatible members. No mandatory narrow proxy. Full gate and independent review required.
