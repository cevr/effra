# Which compilation boundary preserves speed as the language grows?

## Question

What package/interface-summary boundary and cache keys avoid downstream rechecking after a private edit without hiding contract changes? Measure a concrete cold/warm/private/public-edit workload before choosing the next compiler architecture. The current single-file timings are a baseline, not acceptance evidence for a package compiler.
