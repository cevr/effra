# Does explicit run and contract inspection make the tiny language useful?

## Question

Can a runnable `.ef` slice make deferred execution, service provision, and selective error recovery easy to read, while rejecting missing requirements and exposing concise canonical contracts to agents?

Produce a Go compiler with a deliberately small syntax, runnable JavaScript/Effect output, contract diagnostics, and shared CLI/MCP inspection. Unsupported features must be explicit. Record compile timings as evidence, not a claim of Go-equivalent speed. The user's reaction to the artifact is required before resolving this ticket.
