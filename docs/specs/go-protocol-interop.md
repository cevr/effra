# Automatic Go protocol interoperability

Authorized owner constraint, 2026-10-06: preserve the standard native protocols that let Go libraries compose. This finite contract extends [host interop](../interop.md) and [language abstractions](language-abstractions.md). Unit 1 (host types and returns) is implemented as described in [host interop](../interop.md#implemented-go-slice); units 2–4 are not. The [Effect language boundary](../research/effect-language-boundary.md) distinguishes checked language contracts from runtime/library behavior.

## Native type authority

Automatically ingest used exported declarations and their reachable types from module-resolved Go export data. Preserve package-qualified named identity, aliases, native basic kinds, pointers, slices, arrays, maps, structs, interfaces, receiver method sets and ordered result tuples. Unsupported generic forms diagnose. Native `int` and `uintptr` retain their native width; literals and conversions require checked rules rather than silently becoming Effra `i64`. Host nil possibility remains an inspection/boundary fact, never an Effra nil/null value or nullable ordinary type. Adapt optional native values through explicit closed alternatives under the [absence contract](absence-and-host-boundaries.md), including the distinct case of a nonnil interface holding a nil pointer.

Use one consistent `go/types` import universe and its assignment/member authorities. Native structural interface assignment does not introduce unrestricted structural coercion between Effra nominal data. Keep pointer/value method sets and addressability distinct. Signature strings are display output. Imported type/member/callable facts share the canonical revision and bounded CLI/MCP model; over-budget projection refuses explicitly without fabricating a partial type.

Pass an assignable native object to a native interface directly. Preserve concrete dynamic identity and optional methods; no required per-package signature declaration, narrow proxy, reflection registry or JSON round-trip. In particular, `io.Copy` checks the source's `WriterTo` before the destination's `ReaderFrom`. A wrapper that hides those methods changes native behavior. Exact representational bridges may be synthesized; other conversions need explicit checked contracts.

Imported functions and methods remain lazy Foreign operations under the supported trust policy. Capture a receiver once and retain its owner relation in a deferred method recipe. Preserve every native return component and underlying error identity. `(n, error)` can contain useful data and EOF together; `(value, bool)` has no universal Option meaning. Explicit failure adaptation retains partial values and permits native `errors.Is`/`errors.As` where supported. Typed-nil errors are not normalized to success. Native error handles retain the original interface as opaque boundary state; they expose no nil pointer as ordinary Effra data. A source caller inspects absence or error through checked alternatives/helpers, never `err != nil`.

## Lifetimes and behavior

Separate shape from ownership, retention, concurrency and cancellation metadata. Ship reviewed standard-library contracts with imported symbols; applications should not repeat signatures or boilerplate for ordinary native protocols. Unknown behavior stays inspectably unknown. An interface declaration is a trust input for an implementation's behavior, not a compiler proof that arbitrary Go code obeys it.

Define a managed/native File borrow/adopt seam that retains the original object. A borrowed resource does not acquire release authority. An adopted resource has one release authority shared across admitted aliases. Deferred calls, retained host objects and callbacks must carry owner constraints; unsupported escape/alias relations diagnose or cross an explicit trusted boundary. General foreign race freedom and arbitrary alias discovery are not promised.

An [actor mailbox](actors.md) does not confer ownership of native aliases. Initial messages/replies/domain failures contain resource-free portable data; reject Go pointers/slices/maps/interfaces and nested mutable references rather than shallow-copying them. Reviewed copiers/codecs can produce domain snapshots. Native resources may remain actor-owned behind ordinary implementations, preserving native protocol identity locally. Shared DI and unmanaged host work still require explicit concurrency/trust contracts; serialized dispatch is not global race freedom.

`context.Context` forwarding, deadline mutation and close-to-unblock are different contracts. `io.Reader` has no context parameter; its method set does not imply cancellation. `net.Conn` deadlines affect shared pending and future operations, and close can affect other borrowers. Cancellation notification does not establish completed cleanup. Managed shutdown retains the actual foreign-call limitations rather than abandoning an uncooperative goroutine.

A kernel descriptor is a platform-specific borrowed handle, distinct from a native object/interface. `os.File.Fd` can invalidate deadline behavior and must not outlive its owner or receive an independent close. Prefer an explicitly scoped native descriptor callback where applicable. Duplication/transfer establishes a separate lifetime only when a supported native operation proves it. Go-only values and descriptors remain unavailable to JS unless a separate target contract exists.

Pure callbacks with an exact supported native signature may cross directly. An effectful inverse bridge needs an execution owner, provisioned services, declared failure mapping, reentrancy/retention rules and full capture lifetime. It must not silently execute an arbitrary recipe. `http.Handler` requires an explicit publication policy: native ResponseWriter writes alone cannot guarantee cleanup completed before response publication.

## Four gated implementation units

1. **Host types and returns:** canonical reachable foreign identities, native scalar and absence-adaptation rules, used declarations and complete tuples. Exercise ordinary Go int and more than two results; reject unsupported forms/wrong widths. Prove typed-nil error distinction and partial-result/error identity through public source and shared inspection. Native reference nil controls are host evidence, not admitted Effra syntax; source-level nil/null and unchecked unwrapping reject.
2. **Methods and protocols:** native receiver selection and direct interface assignment. Use native buffers/readers with `io.Copy`, filesystem interfaces and optional directory methods. A counting `WriterTo`/`ReaderFrom` control proves dispatch without a timing claim. Cover pointer/value method sets, incompatible signatures, data plus EOF, short writes and offset-independent reads.
3. **Owned host resources:** managed/native File borrowing/adoption, aliases, retained/deferred escape and separately owned handles. Local files and `net.Pipe` prove late acquisition cleanup, pending-I/O interruption policy and completed shutdown. Borrowed standard streams must not close. Unknown cancellation must remain distinct from reviewed context/deadline/close behavior.
4. **Callbacks and inverse interfaces:** exact pure callbacks, then scoped effectful bridges. A real imported SDK returning a callback-backed text writer tests chunked writes and close-flushed remainder without handwritten signatures; another retained-reader/writer fixture tests lifetime escape. Preserve generic public examples and record exact private source pins separately. An unavailable dependency is an acceptance gap, not a passing substitute. Handler bridge tests publication/cleanup and explicit failure mapping.

Every unit compiles and passes the full gate; native lifecycle changes add race checks. Actual CLI/MCP and native executable acceptance must agree on target, revision, host type, adaptation, ownership and trust provenance. Keep the primitive importer regression corpus. Native-only source must diagnose on JS before launching Go tools; Go-only builds never start TypeScript.

Project only selected declarations and reachable member/type graphs. Library/type availability must not retain unused runtime implementations or startup registration. This differs from a user-declared foreign import, which is itself a package-initialization dependency retained independently of reachable calls ([foreign package initialization](binary-reachability.md#foreign-go-package-initialization)); module availability, export-data discovery and metadata lookup alone are never initialization roots. Version importer facts with toolchain, target/build settings, module/export identity, behavior metadata and compiler schema. Import/cache/reachability and binary-size measurements belong to the final measurement phase, with raw receipts before any speed or size claim.

Borgo's pinned interface inference fixture is a type-checking precedent, not lifetime or cancellation evidence. Source review and a privately retained external SDK comparison establish the proposed acceptance boundaries; none counts as executed Effra host-protocol support.
