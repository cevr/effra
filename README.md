# Effra

An experimental language for servers: explicit, inspectable effect contracts, `.ef` source, and the `ef` command.

This repository is a prototype, not a production language. The [design sketch](docs/design.md) records the wider proposal; implemented features are documented separately.

The [Effra prototype map](docs/wayfinder/issues/map.md) tracks the remaining decisions. Query the frontier with `python3 scripts/wayfinder.py frontier`.
